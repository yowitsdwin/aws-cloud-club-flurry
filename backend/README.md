# AWS Cloud Club Flurry - Backend 🌩️⚙️

This is the Node.js + Fastify backend for the **AWS Cloud Club Flurry** membership system. It connects to PostgreSQL via Supabase.

## 🚀 Getting Started

### 1. Installation

From the root directory:
```bash
cd backend
npm install
```

### 2. Configure Environment Variables

Copy the `.env.example` file to `.env`:
```bash
cp .env.example .env
```
Open `.env` and configure your **Supabase URL** and **Anon Key** (or **Service Role Key** if bypassing RLS policies).

---

### 3. Database Setup (Supabase)

To prepare your Supabase database, run the following SQL script in your **Supabase SQL Editor** to create the `memberships` table:

```sql
CREATE TABLE memberships (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    first_name TEXT NOT NULL,
    last_name TEXT NOT NULL,
    middle_name TEXT,
    nickname TEXT,
    email TEXT NOT NULL UNIQUE,
    student_id TEXT NOT NULL UNIQUE,
    birthdate DATE NOT NULL,
    college TEXT NOT NULL,
    program TEXT NOT NULL,
    year_level TEXT NOT NULL,
    facebook TEXT,
    linkedin TEXT,
    github TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Optional: Create indexes for fast lookup on unique identifiers
CREATE INDEX idx_memberships_email ON memberships(email);
CREATE INDEX idx_memberships_student_id ON memberships(student_id);
```

---

### 4. Running the Server

To start the development server with automatic reloading:
```bash
npm run dev
```

To run in production:
```bash
npm run start
```

The API will be available at `http://localhost:3000/api`.

- **Health check**: `GET http://localhost:3000/health`
- **Apply for Membership**: `POST http://localhost:3000/api/memberships`
- **Retrieve Applications**: `GET http://localhost:3000/api/memberships`
