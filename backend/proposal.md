## AWS Cloud Club Flurry Backend 🌩️⚙️

## Key Requirements Addressed

1. **Opaque & Permanent IDs:** 8-character lowercase alphanumeric strings (`[a-z0-9]{8}`). They are generated once at registration, independent of mutable fields like departments, college, or semester renewals.
2. **Unguessability & Brute-Force Mitigation:** With `36^8 ≈ 2.82 × 10^12` total combinations, guessing valid IDs is computationally infeasible for malicious actors.
3. **Dual Verification Channels:** Primary event check-in via QR Code scans (containing the ID); fallback via manual alphanumeric typing.
4. **Idempotence & Duplicate Prevention:** Multi-column uniqueness constraints block duplicate applications.
5. **Officer Authorization:** Managed entirely via Google Sign-In matching the verified email against the internal database `role` matrix. Regular members do not possess login credentials.

# 2. Database Schema Modifications (Supabase / PostgreSQL)

Execute the following DDL script inside the Supabase SQL Editor to append metadata, optimize index routing, and set up relational safety for attendance tracking.

```sql
-- Upgrading memberships table with Identity and Access Control layers
ALTER TABLE memberships
ADD COLUMN member_id VARCHAR(8) UNIQUE,
ADD COLUMN role TEXT NOT NULL DEFAULT 'Member' CHECK (role IN ('Member', 'Officer', 'Lead')),
ADD COLUMN is_active BOOLEAN NOT NULL DEFAULT true,
ADD COLUMN department TEXT;

-- Create high-performance index for rapid QR scan lookups
CREATE INDEX IF NOT EXISTS idx_memberships_member_id
ON memberships(member_id);

-- Create downstream Event and Attendance structural components
CREATE TABLE IF NOT EXISTS events (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    description TEXT,
    event_date TIMESTAMP WITH TIME ZONE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

CREATE TABLE IF NOT EXISTS event_attendance (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    event_id BIGINT REFERENCES events(id) ON DELETE CASCADE,
    member_id VARCHAR(8) REFERENCES memberships(member_id) ON DELETE RESTRICT,
    scanned_by VARCHAR(8) REFERENCES memberships(member_id), -- Officer who scanned
    marked_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,

    -- Prevent duplicate attendance records
    UNIQUE (event_id, member_id)
);

CREATE INDEX IF NOT EXISTS idx_attendance_composite
ON event_attendance(event_id, member_id);
```

# 3. Core Logic Implementation

## 3.1 ID Generation & Verification Pipeline (`crypto`-based)

The logic must operate within a deterministic loop ensuring cryptographic distribution, profanity filtering, and reactive database collision checking.

```javascript
import { randomBytes } from 'crypto';

/**
 * Generates an 8-character lowercase alphanumeric string.
 */
function generateRandomID() {
  const chars = 'abcdefghijklmnopqrstuvwxyz0123456789';
  let result = '';
  const bytes = randomBytes(8);

  for (let i = 0; i < 8; i++) {
    result += chars[bytes[i] % chars.length];
  }

  return result;
}

/**
 * Basic profanity filter.
 */
const BANNED_WORDS = [
  'badd',
  'wrd1',
  'wrd2',
  'scam',
  'spam',
  'hack',
  'sh1t',
  'fcku'
];

function isClean(id) {
  return !BANNED_WORDS.some(word => id.includes(word));
}

/**
 * Generates a unique Member ID.
 */
export async function createUniqueMemberID(supabaseClient) {
  let attempts = 0;
  const MAX_ATTEMPTS = 10;

  while (attempts < MAX_ATTEMPTS) {
    attempts++;

    const candidateId = generateRandomID();

    if (!isClean(candidateId)) continue;

    const { data } = await supabaseClient
      .from('memberships')
      .select('member_id')
      .eq('member_id', candidateId)
      .maybeSingle();

    if (!data) {
      return candidateId;
    }
  }

  throw new Error(
    'ID generation exceeded maximum threshold limits. Check database constraints.'
  );
}
```

## 3.2 Membership Registration Endpoint (`POST /api/memberships`)

```javascript
fastify.post('/api/memberships', async (request, reply) => {
  const {
    first_name,
    last_name,
    middle_name,
    nickname,
    email,
    student_id,
    birthdate,
    college,
    program,
    year_level,
    facebook,
    linkedin,
    github,
    department
  } = request.body;

  try {
    // Generate immutable Member ID
    const memberId = await createUniqueMemberID(fastify.supabase);

    const { data, error } = await fastify.supabase
      .from('memberships')
      .insert([{
        member_id: memberId,
        first_name,
        last_name,
        middle_name,
        nickname,
        email,
        student_id,
        birthdate,
        college,
        program,
        year_level,
        facebook,
        linkedin,
        github,
        department,
        role: 'Member',
        is_active: true
      }])
      .select()
      .single();

    if (error) {
      if (error.code === '23505') {
        return reply.code(400).send({
          error: 'Duplicate Application Detected',
          message:
            'The email address or student ID provided has already been registered.'
        });
      }

      throw error;
    }

    return reply.code(201).send({
      success: true,
      message: 'Membership application submitted successfully.',
      member_id: data.member_id
    });

  } catch (err) {
    fastify.log.error(err);

    return reply.code(500).send({
      error: 'Internal Server Error processing membership payload.'
    });
  }
});
```

# 4. Google Authentication & Authorization Matrix

Officers authenticate exclusively through Google Sign-In.

```javascript
import { OAuth2Client } from 'google-auth-library';

const client = new OAuth2Client(process.env.GOOGLE_CLIENT_ID);

fastify.post('/api/auth/google-login', async (request, reply) => {
  const { idToken } = request.body;

  try {
    const ticket = await client.verifyIdToken({
      idToken,
      audience: process.env.GOOGLE_CLIENT_ID
    });

    const payload = ticket.getPayload();
    const googleEmail = payload.email;

    const { data: member } = await fastify.supabase
      .from('memberships')
      .select('member_id, role, first_name, is_active')
      .eq('email', googleEmail)
      .maybeSingle();

    if (!member) {
      return reply.code(403).send({
        error: 'Unauthorized Identity',
        message: 'This email is not registered in the system.'
      });
    }

    if (!member.is_active) {
      return reply.code(403).send({
        error: 'Deactivated Identity',
        message: 'Your system privileges have been suspended.'
      });
    }

    if (
      member.role !== 'Officer' &&
      member.role !== 'Lead'
    ) {
      return reply.code(403).send({
        error: 'Insufficient Privileges',
        message:
          'Access denied. Regular members do not possess backend portal access.'
      });
    }

    const sessionToken = fastify.jwt.sign({
      member_id: member.member_id,
      role: member.role
    }, {
      expiresIn: '8h'
    });

    return reply
      .code(200)
      .setCookie('session_token', sessionToken, {
        path: '/',
        secure: true,
        httpOnly: true,
        sameSite: 'strict'
      })
      .send({
        success: true,
        user: {
          name: member.first_name,
          role: member.role,
          member_id: member.member_id
        }
      });

  } catch (err) {
    fastify.log.error(err);

    return reply.code(401).send({
      error: 'Authentication Failed',
      message: 'Invalid token identity payload.'
    });
  }
});
```

# 5. Event Verification Check-In (`POST /api/attendance/scan`)

```javascript
fastify.post('/api/attendance/scan', async (request, reply) => {
  const officerId = request.user.member_id;
  const { target_member_id, event_id } = request.body;

  try {
    const { data: targetMember } = await fastify.supabase
      .from('memberships')
      .select('is_active')
      .eq('member_id', target_member_id)
      .maybeSingle();

    if (!targetMember) {
      return reply.code(404).send({
        error: 'Invalid Pass',
        message: 'No registered member matches this identifier.'
      });
    }

    if (!targetMember.is_active) {
      return reply.code(400).send({
        error: 'Suspended Pass',
        message: 'This member card is flagged inactive.'
      });
    }

    const { error } = await fastify.supabase
      .from('event_attendance')
      .insert([{
        event_id,
        member_id: target_member_id,
        scanned_by: officerId
      }]);

    if (error) {
      if (error.code === '23505') {
        return reply.code(409).send({
          error: 'Already Checked-In',
          message:
            'This member has already been recorded for this event.'
        });
      }

      throw error;
    }

    return reply.code(200).send({
      success: true,
      message: 'Attendance recorded accurately.'
    });

  } catch (err) {
    fastify.log.error(err);

    return reply.code(500).send({
      error: 'Database record processing failures occurred.'
    });
  }
});
```
